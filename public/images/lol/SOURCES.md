## XYZ branded derivatives

`boosting-branded.webp`, `duo-branded.webp`, and `account-branded.webp` are image_gen edits of the corresponding source artwork, adding Korean service typography, XYZ watermark, dark gradients, and gold framing. These are branded edited compositions, not unmodified official artwork. No Riot endorsement is implied. Original source files above remain available for provenance.

## Uniform typography series (previous)

`boosting-uniform.webp`, `duo-uniform.webp`, `account-uniform.webp`, and `leveling-uniform.webp` use original Riot artwork with a common editable vector template. All lettering is outlined from Gmarket Sans Bold at the same font sizes and baseline coordinates; there is no XYZ watermark. The source SVG files are in `design/service-banners`, generated by `scripts/build-service-banners.py` (requires Python fonttools, project sharp, and FONT_PATH to GmarketSansTTFBold.ttf). The exported WebP files contain the lettering in the image itself.

- `garen.webp`: https://ddragon.leagueoflegends.com/cdn/img/champion/splash/Garen_0.jpg (retrieved 2026-09-18).

## Centered typography correction (current)

The four `*-centered.webp` banners preserve the same artwork and use Noto Sans KR at weight 700. All titles are 112px, centered at x=768 with baseline y=828; all subtitles are 44px with baseline y=909. Flat gold lettering replaces the per-glyph gradient, and a single centered ornament replaces the right-hand box. There are no XYZ watermarks. Editable sources are `design/service-banners/*-centered.svg`.
